# R6 3.6 Twin-Turbo: интерактивный 3D-симулятор двигателя

Одностраничное приложение (один файл `index.html`, без сборки): рабочая 3D-модель рядной «шестёрки» объёмом 3,6 л с твин-турбо, коробкой-роботом, полным приводом, приборами, педалями и звуком. Всё считается и рисуется в браузере.

> Это упрощённая учебно-демонстрационная модель. Цифры мощности, расхода, температур и разгона ориентировочные и не являются данными реального двигателя.

## Возможности

- **3D-модель** на three.js: поршни, шатуны, коленвал, два распредвала с гоночными кулачками, три клапана на цилиндр (два впускных, один выпускной, титановые, с двойными пружинами), индивидуальные дроссели, кованые поршни, лёгкий маховик, твин-турбо с интеркулером, радиатор с вентилятором, масляная система, робот с двумя сцеплениями и 7 передачами, полный привод с раздаточной коробкой и карданными валами.
- **Рабочий цикл**: порядок работы 1–5–3–6–2–4, камеры сгорания окрашены по тактам, свечи, искра, хлопки.
- **Четыре режима мощности**: Комфорт, Спорт, Спорт+, Гоночный. У каждого свои отсечка, наддув, педаль, переключения, антипробуксовка, звук. Мощность на кнопках рассчитывается той же формулой, что и симуляция.
- **Приборы** в стиле приборной панели BMW E60: обороты, скорость, наддув, мощность, расход топлива, уровень топлива, температура охлаждающей жидкости и масла, давление масла. Светодиодная шкала переключения, одометр и суточный пробег.
- **Педали газа и тормоза** с аналоговым нажатием, пружинным возвратом, ABS, стоп-сигналом и управлением с клавиатуры.
- **Физика**: твин-турбо с турбоямой и перепускным клапаном, коробка с двумя сцеплениями и предвыбором, полный привод и сцепление с дорогой, карбон-керамические тормоза с перегревом, нагрев охлаждающей жидкости и масла, расход топлива.
- **Звук**, синтезируемый в реальном времени (Web Audio): импульсы зажиганий, резонанс выхлопа, свист турбин, хлопки.
- **Графика**: мягкие тени, кинематографическая цветокоррекция, адаптивное разрешение. Если устройству не хватает кадров, тени отключаются сами.

## Управление

| Действие | Как |
|---|---|
| Запуск и остановка | Большая кнопка «Запуск» |
| Газ | Педаль газа (нажать и вести вдоль неё), клавиши ↑ или W |
| Тормоз | Педаль тормоза, клавиши ↓, S или пробел |
| Включить 1-ю передачу | Кнопка «+», затем автомат переключает сам |
| Ручные переключения | Снять переключатель «Автомат», кнопки «+» и «−» |
| Камера | Вращение пальцем или мышью, масштаб щипком или колесом |

## Запуск

Откройте `index.html` в браузере. Нужен интернет: three.js (r128) и шрифт загружаются с CDN.

Локальный сервер, если нужен:

```bash
python3 -m http.server 8000
# откройте http://localhost:8000
```

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите файлы.
2. **Settings → Pages → Build and deployment**: источник `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту страница откроется по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Технологии

HTML, CSS, JavaScript без сборки, three.js r128 (CDN), Canvas 2D для приборов, Web Audio API для звука, `localStorage` для пробега и выбранного режима.
